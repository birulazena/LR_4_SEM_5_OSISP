## Описание

Консольное приложение на C++, моделирующее конкурентную работу потоков (философов) с доступом к общим ресурсам (вилкам) с использованием механизмов синхронизации Windows API (`Mutex`). Для предотвращения взаимных блокировок (*deadlock*) реализован асимметричный захват ресурсов.

---

## Требования к среде выполнения

- **ОС:** Windows 11
- **Компилятор:** MinGW-w64 (g++ 16.2.0)
- **Python:** для построения графиков и запуска автотестов

## Инструкции по сборке

Для компиляции исходного кода откройте терминал в корневой папке проекта и выполните команду:

```bash
g++ src/main.cpp -o main.exe
```

---

## Параметры запуска

Программа принимает параметры через аргументы командной строки:

```text
main.exe <philosophers> <cycles> <think_time> <eat_time> <max_wait_ms> [quiet_mode]
```

- `philosophers` — количество потоков (философов).
- `cycles` — количество циклов работы для каждого философа.
- `think_time` — базовое время размышления (мс).
- `eat_time` — время приема пищи / использования ресурса (мс).
- `max_wait_ms` — максимальное время ожидания ресурса (тайм-аут в мс).
- `quiet_mode` *(опционально)* — `1` для отключения подробного журнала событий, `0` для включения (по умолчанию `0`).

### Пример запуска

Запуск со стандартными параметрами и выводом логов:

```powershell
.\main.exe 5 100 2 10 5000 0
```
